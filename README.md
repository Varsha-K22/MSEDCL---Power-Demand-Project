⚡ Maharashtra Power Demand Analytics Dashboard
📌 Project Overview

This project presents an interactive Power Demand Analytics Dashboard developed to analyze electricity demand trends in Maharashtra using data from Maharashtra State Electricity Distribution Company Limited (MSEDCL).

The dashboard provides insights into peak demand patterns, seasonal variations, monthly trends, and year-over-year comparisons, helping stakeholders understand electricity consumption behavior and identify critical demand periods.

🎯 Project Objectives
Analyze electricity demand trends across Maharashtra.
Identify peak demand periods and corresponding dates.
Compare Morning, Day, and Evening demand patterns.
Evaluate seasonal variations in electricity consumption.
Monitor monthly and yearly demand fluctuations.
Create an interactive dashboard for data-driven decision-making.
